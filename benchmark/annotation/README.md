# Construction records

`AmbiTab_Sports_Final_Construction_Adjudication.xlsx` is an exported view of the canonical 360-row benchmark, with current source-status fields. It is the final release view, not a chronological adjudication log.

The original completed A/B workbooks preserve source annotation values. Their author metadata is anonymized. `AmbiTab_Sports_Full_Master_Adjudication.xlsx` is a **historical unfinished starter** with 497 open dispute entries and six blank final-track cells; its open statuses are intentionally preserved. No historical decisions, reasons, or timestamps are invented. Final CSV decisions are supplied release fields, whose historical adjudication chronology remains incompletely documented.
